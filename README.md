# Python个性化电影推荐系统简介

## 核心功能
- 用户登录注册
- 协同过滤推荐
- 电影分类
- 排序
- 搜索
- 评分
- 收藏
- 电影评论词云
- 基于用户推荐
- 基于项目推荐

## 适用场景
- 个性化电影推荐服务
- 电影爱好者社区
- 电影相关研究项目

## 技术特点
- 使用Django框架
- 基于MySQL数据库
- 使用Bootstrap3进行前端开发
